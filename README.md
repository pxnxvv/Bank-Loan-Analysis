# Bank-Loan-Analysis-SQL
Bank loan analysis using MySQL to explore customer demographics, loan portfolios, payment records, and default risk.
Project Overview
This project uses MySQL to analyze customer demographics, loan portfolios, loan statuses, and payment records. It demonstrates fundamental SQL queries used to explore banking data and identify useful business insights.
Objectives
- Analyze customer income, age, credit scores, and locations.
- Examine loan distribution by type and status.
- Identify defaulted loans and unpaid payment records.
- Calculate total loan amounts, average loan values, and payment summaries.
- Practice data retrieval, filtering, aggregation, and joins using SQL.
Tools Used
- MySQL
- SQL
SQL Concepts Covered
- Database and table creation
- INSERT and SELECT statements
- WHERE, ORDER BY, DISTINCT, and LIKE
- Aggregate functions: COUNT, SUM, AVG, MAX, MIN
- GROUP BY
- INNER JOIN and LEFT JOIN
- BETWEEN and IS NULL
Files
- bank_loan_analysis.sql — SQL script containing database setup, sample data, and analysis queries.
How to Run
1. Open MySQL Workbench or another MySQL client.
2. Open bank_loan_analysis.sql.
3. Execute the script to create the database, tables, and sample records.
4. Run the analysis queries to explore the results.
Note
This project uses sample data for learning and demonstration purposes.
